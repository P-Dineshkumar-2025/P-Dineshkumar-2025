## 🧠 What I Have Learned with Git

```bash
git init                       # start a repository
git add .                      # stage files
git config --global user.name  "Your Name"
git config --global user.email "your-github-noreply-email"
git commit -m "Initial commit" # save a snapshot
git remote add origin <repo-url>
git push -u origin master      # upload to GitHub
```

- Fixed the **"Author identity unknown"** error by configuring my name and email.
- Learned to use `git commit -m` instead of the default Vim editor.
- Learned to use my GitHub **no-reply email** so commits link to my profile.
